Survey Data

This repository contains the survey data collected for the manuscript: "Seen but not punished: The detection–response gap in Vietnamese Generation Z consumers' reactions to greenwashing". Submitted to Journal of International Consumer Marketing.

The data were exported directly from Google Forms. Each file is provided in the original Vietnamese (VNM) and in an English translation (ENG).

---

## 1. Study overview

| Item | Description |
|---|---|
| Design | 2 (claim type: substantiated vs. greenwashing) × 2 (source credibility: high vs. low) between-subjects online vignette experiment |
| Stimulus | Fictitious domestic fashion brand (*EcoWave Vietnam*) advertising a basic organic cotton T-shirt at a fixed price of VND 299,000 |
| Population | Vietnamese Generation Z consumers aged 18–27 who had purchased apparel in the previous 12 months |
| Data collection | Online questionnaire (Google Forms), 15–26 July 2026 |
| Raw responses | 311 |
| Analytic sample | 233 (A1 = 58, A2 = 58, B1 = 61, B2 = 56) |
| Language of instrument | Vietnamese (English rendering provided in the codebook) |

### Experimental conditions

| Code | Claim type | Source credibility |
|---|---|---|
| A1 | Substantiated | High |
| A2 | Substantiated | Low |
| B1 | Greenwashing | High |
| B2 | Greenwashing | Low |
